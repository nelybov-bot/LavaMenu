# Совместимость LavaMenu с другими модами

## Папка модов

Складывайте JAR соседних модов сюда:

```
LavaMenu/mods/
```

При установке в игру копируйте **все** JAR из `release/` и `mods/` в `.minecraft/mods/`.

## Статус проверки

| Мод | Версия | MC | Статус | Заметки |
|-----|--------|-----|--------|---------|
| lavamenu | 0.1.0 | 26.1.x | базовый | этот мод (`release/lavamenu-0.1.0.jar`) |
| Inventory Profiles | ? | 26.1.x | частично → фикс анимаций | «Лечь»/смена анимации дергало инвентарь (Shift); исправлено sneak-пакетом |

**Статусы:** `не проверено` · `ок` · `конфликт` · `частично` (работает с оговорками)

## На что смотреть при проверке

1. **Запуск** — игра стартует без краша (лог `latest.log`).
2. **Клавиши** — R / G (и переназначенные) не перехватываются другими модами.
3. **GUI** — основное и быстрое меню открываются, кнопки кликаются.
4. **Команды** — `/homes`, `/ah`, `/sit`, `/lay`, телепорт точек.
5. **Чат** — парсер точек из ответа сервера (`LAVA > Список...`).
6. **Рендер** — иконка в центре radial, нет missing texture.

## Известные риски

- Другие моды с **перехватом клавиш** (меню, макросы, radial) — возможен конфликт хоткеев.
- Моды, **меняющие чат** или формат сообщений — может сломаться парс `/homes`.
- **Client-only** — LavaMenu не требует серверного мода; серверные моды на совместимость не влияют.
